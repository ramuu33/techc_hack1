# 読み上げ用の台本

当日そのまま読むためのもの。〔 〕は操作と間の指示で、読み上げない。
準備チェックリスト・事故対策・想定質問は [demo-script.md](demo-script.md) にある。

## 書き方の方針

聞き手は**同世代の学生**で、総合賞はその人たちの投票で決まる。
専門用語や、意味の詰まった短い言い回しは、初めて聞く人には音として通り過ぎる。

そこで **具体 → 抽象** の順を徹底している。先に情景や例を言って、そのあとに名前を付ける。
「自分の前提が見えた」だけでは伝わらないが、
「同じ『家』という言葉に、違うものを見ていた」を先に言えば、そのあとの一言が届く。

避けた言い方と、置き換えた言い方:

| 使わない | 代わりに言う |
|---|---|
| 自分の前提 | 自分が当たり前だと思っていること |
| 宛てられると防御が立つ | 自分に向けて言われると、人は身構えてしまう |
| 転送が原理的に不可能 | 転送ボタンがない。というより、作れない |
| 気づきの所有権 | それはもう、自分で気づいたことにならない |
| 影響の来歴 | どの言葉を読んで書かれたか |
| 再帰クエリ1回 | 1回の検索でたどれる |

## 分量(実測)

デモ中は操作で黙っている時間があるので、デモの内と外を分けて測っている。

| | 全部読む | 〔飛ばす〕を落とす |
|---|---|---|
| デモ以外(6分40秒) | 3,027字 → **454字/分** | 2,314字 → **347字/分** |
| デモ中の語り(実質2分) | 526字 → 263字/分 | 434字 → 217字/分 |

落ち着いて話せるのは300〜330字/分。**全部読むと確実に溢れる。**
〔押していたら飛ばす〕の6か所を落とせば347字/分で、少し速いが最後まで話しきれる。

逆に〔余裕があれば言う〕は、**時間が余ったときにだけ足す一言**。無理に入れなくてよい。

**捨て札は先に決めておくこと。**その場で判断すると必ず失敗する。
落とす順は ①できていること ②他の人の軌跡 ③既存サービスの説明 ④デザインの話
⑤工夫の2つめ ⑥これから(再会)。

「このサービスの価値」「4世代」「この言葉から、ことづてが生まれました」は
**どれだけ押しても削らない。**配点に直結する。

## 0:15 つかみ

母に「掃除しろ」と言われて、何度もケンカしました。「普通はやるものでしょ」って。

しばらくして、気づいたことがあります。これ、掃除の話じゃなかったんです。

私にとって家は、疲れを取る場所でした。だから散らかっていても平気だった。母にとって家は、家族みんなで暮らす土台でした。だから散らかっていると困る。

どちらが正しいという話ではありません。**同じ「家」という言葉に、違うものを見ていた。** それだけでした。

そして大事なのは、母を理解できたことじゃないんです。**自分が何を当たり前だと思っていたのか、生まれて初めて見えた**ことでした。

## 0:55 課題

自分にとっての当たり前って、当たり前すぎて、疑うことすらしないですよね。

見えるのは、違う考えに触れたときだけです。私も、母とぶつかるまで気づきませんでした。

じゃあ、違う考えに触れる場所は、いまどこにあるか。

〔ひと呼吸おく〕

SNSはあります。でも、いちばんそれを必要としている人にとって、あそこは安全な場所ではありません。

## 1:15 誰のためのサービスか

このサービスは、自分の中で考えすぎる人のために作りました。人に気を使いすぎて、言いたいことを飲み込んでしまう人です。

たとえば、会議で「それ違うかも」と思っても、言えずに「まあいいか」で終わらせてしまう。そういう人です。

## 1:35 いまある場所が効かない理由

その人にとって、いまある場所がなぜ効かないのか。

〔押していたら飛ばす — ここから2段落。表を見せるだけでも伝わる〕

SNSでは、自分に向けて返信が来ます。「それは違うと思う」と自分宛てに言われたとき、内容を考えるより先に「言い返さなきゃ」という気持ちが来ませんか。**自分に向けて言われると、人は身構えてしまう。** しかも名前を出して言ったことは、あとから引っ込めるのも難しい。

名言アプリは、いい言葉を読んで終わりです。自分の側は何も動かない。日記アプリは自分の中だけで完結するので、自分の当たり前は、結局見えないままです。

〔ここまで。以下は必ず言う〕

じゃあ人に相談すれば、と思われるかもしれません。でも相談って、相手にも気を使いますよね。**そもそも、それができない人の話をしています。**

必要なのは、**自分とまったく関係ないところで生きている人の、頭の中を覗くこと**でした。

## 2:00 このサービスの価値

〔4つのマスを順に指す。ここは何があっても飛ばさない〕

誰の話か。自分の中で考えすぎる人です。

何が課題か。自分の当たり前が見えない。そして、それに気づける安全な場所がない。

どう解決するか。**誰にも宛てられていない、他人の言葉が、1日1回だけ届きます。** 心が動いたら、書く。返信も、いいねも、来ません。

どんな効果があるか。自分の当たり前が見えます。そしてもう1つ、**自分の書いた言葉が、誰かの当たり前を動かしたことが、返ってきます。**

## 2:20 循環

仕組みは、これだけです。

1日1回、言葉が届く。心が動いたら、自分の言葉を書く。その言葉が、明日、別の誰かに届く。

**この輪だけ**でできています。コメントも、いいねも、フォローも、通知もありません。

## 2:40 デモ

〔本番URLに切り替える〕

〔名前を入れて「はじめる」→「受け取る」〕

夜の画面に、点がひとつ届いています。受け取ります。

〔来歴の部分を指す〕

ここに、この言葉がどこから生まれたかが出ています。

こもれびさんが、三日坊主さんの言葉を読んで書いた。三日坊主さんは、のらねこさんの言葉を読んで。のらねこさんは、芥川龍之介の言葉を読んで。**4世代さかのぼれます。**

〔その場で書いて「ことづてを託す」。内容は事前に決めておく〕

〔/demo →「他の全員に届ける」→ ホームへ〕

「あなたの言葉を、今日◯人が受け取りました」と出ました。

本当は相手がアプリを開いたときに届きますが、今日は待てないので、同じ処理をその場で起こしました。

〔/demo → のらねことして開く → わたしの軌跡。**ここが山場。ゆっくり**〕

今度は書いた側の画面です。のらねこさんとして開きます。

ここに、こう出ています。**「この言葉から、ことづてが生まれました」。** 三日坊主さんの言葉です。

これ、返信ではありません。三日坊主さんは、のらねこさんに宛てて書いていないし、宛てて書く機能もない。**返ってきているのは、自分の言葉が誰かの考えを動かした、という事実だけ**です。

思想家って、教科書に載っている人のことだと思っていました。でも、**誰かの考えを変えた人**のことだとしたら — いまこの画面ののらねこさんは、もうその条件を満たしています。

〔押していたら飛ばす — 他の人の軌跡は、操作ごと省略できる〕

もう1つだけ。軌跡は、1本の線の上に点が並んでいきます。書けた日は塗りつぶした点、書けなかった日は白い点です。書けない日があっていい設計にしました。毎日書く義務にすると、続かないので。

これまでは、違和感があっても「まあいいか」で終わって、モヤモヤは言葉にならないまま消えていました。

ここでは、「黙るのは中立じゃない」というまったく知らない誰かの一文が届いて、そこで初めて先月の自分が見える。

そして書いた言葉が、明日、別の誰かのところに届きます。

## 6:20 受け渡されているのは、考えではない

〔4人の名前を左から順に指す。ここが独自性の山場〕

さっきの4世代を、もう一度見てください。

**内容が、全部違うんです。**

芥川は、常識について書きました。のらねこさんは、自分が黙ってきたことに気づいた。三日坊主さんは、会議で黙るのは賛成したのと同じだったと気づいた。こもれびさんは、友達の悪口に黙っていた自分を思い出した。共通する内容が、1つもありません。

残っているのは「この言葉がなければ、この言葉は生まれなかった」というつながりだけです。

〔ひと呼吸おく〕

リツイートって、押すだけで同じ文がそのまま広がりますよね。ここには、そのボタンがありません。**というより、作れないんです。**

書くのは感想ではなく「自分がどう動いたか」なので、**内容は必ず変わってしまう。**変わらないと、そもそも成立しない仕組みになっています。

## 7:00 独自性は1カラム

〔GitHubに切り替える。ここから最後まで出したままにする〕

リポジトリはこちらです。

やったことは、実はすごく単純です。**データベースの表に、列を1つ足しただけ**です。

**「この言葉は、どの言葉を読んで書かれたか」**を記録する列。それだけで、さっきの4世代が、1回の検索でたどれます。

名言アプリにも、日記アプリにも、匿名SNSにも、この列はありません。**独自性は、この列1つです。**

## 7:25 アーキテクチャ

Next.js という仕組みを使っています。

普通は、見た目を作る部分と、処理をする部分を、別々のサーバーに分けます。でもこのサービスは、外から使えるAPIを公開する予定も、スマホアプリを作る予定もありません。**分ける理由がなかったので、1つにまとめました。**

そのおかげで、**ブラウザからデータベースに直接つなぐ経路は、1本もありません。** データベースを触るコードは、全部サーバー側にまとめてあります。

〔余裕があれば言う — 設計の限界を分かっていることが伝わる〕

もし使う人が増えたら、たぶん最初に切り出すのは配信の処理です。1日1回の抽選は、全員分をまとめて夜のうちに走らせたほうが速いので。いまは開いた人の分だけその場で計算しています。

## 7:50 データ構造

表は3つだけです。

ここが一番の工夫で、**偉人の言葉も、ユーザーの言葉も、同じ表に、同じ形で入っています。** 分けていません。

「誰でも思想家になれる」という考えを、**データの形そのもので表しました。**

## 8:15 工夫・苦労した点

1つめ。偉人の言葉48件は、全部、原典を自分で読んで手で書き写しました。

ネットの名言って、実は本人が言っていないものにされていることがすごく多いんです。なので全部に出典のURLを付けて、訳したものは原文も載せました。誰でも確かめられます。

そして**AIに名言を作らせたものは1件もないし、アプリが動いているときもAIは1回も呼んでいません。**

システムに「あなたはこういう人ですね」と言われた瞬間、それはもう、自分で気づいたことになりませんよね。

〔押していたら飛ばす — 2つめは落とせる〕

2つめ。**いちばん最初に受け取る言葉は、必ず「どこから生まれたか」が付いているものにしています。** 最初の1個がただの名言だと、面白いところが伝わらないまま終わってしまうので。

そしてあまり配られていない言葉から優先して配ります。せっかく書いた言葉が、誰にも読まれないまま埋もれないように。

〔押していたら飛ばす — デザインの話は落とせる〕

3つめ。デザインです。最初は、手紙をめくるような見た目で作って、途中で全部捨てました。

ことづては、口で運ばれる言葉なので、紙じゃないんです。いまは点と線だけでできています。

## 9:40 締め

いま、この場で私が書いた言葉は、明日、誰かのところに届きます。

母とのケンカから始まった企画ですが、このサービスは、ケンカを解決する道具ではありません。

できるのは、**ぶつかる前に、自分が何を当たり前だと思っているのか、それが見える機会を1日1回つくること**だけです。

それで十分に価値があると、私は思っています。

〔2秒黙る。QRを出したまま質疑へ〕
