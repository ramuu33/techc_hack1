# 収録テキストの出典と著作権について

本プロジェクトが収録する「偉人の言葉」([data/words.seed.json](../data/words.seed.json)) は、**すべてパブリックドメイン(著作権保護期間満了)の資料から採取**している。
生成AIに名言を作らせたものは一件も含まれていない。すべて原典の本文を実際に取得し、そこから採っている。

原文の言語や時代が読解の壁になるもの(漢文・英文・文語)は現代日本語に訳しているが、
**訳したものには必ず原文を併記**しており、照合できる。訳出の方法は[後述](#訳出の方法について明記しておく)する。

---

## 選定の2つの基準

収録するかどうかは、**2つの基準**で決めている。

1. **出典が確かで、パブリックドメインであること**(以下で詳述)
2. **読んで意味が取れること**

2つ目は実際にアプリを使ってみて追加した基準である。
出典が正しくても、文語調の警句や抽象名詞が重なった文は、スマートフォンで1日1回受け取る形式だと
意味が取れないまま流れてしまう。「難しい」ではなく「像が結ばない」ものは、
心が動くきっかけにならないため落とした。

この基準で **18件を除外**している(芥川『侏儒の言葉』7件・三木『人生論ノート』6件・
宮沢『農民芸術概論綱要』4件、および発表の場でランダムに出ると扱いに困るもの1件)。
除外したものも権利上は問題がなく、収録可能である。

### 直すのは言葉づかいだけで、難しさは残す

残したもののうち、**文語表現と難語のせいで読めないもの6件は現代語にした**(原文は `original` に併記)。
一方、**概念として難しいものはそのままにしている**。

| 例 | 扱い |
|---|---|
| 「阿呆はいつも彼以外の人人を悉く阿呆と考えている」 | **現代語にする**(「悉く」「人人」が読みを止める) |
| 「不確実なものが確実なものの基礎である」 | **そのまま**(語は平易で、難しいのは中身のほう) |

読めないことは障害だが、考えさせられることはこのプロダクトの目的そのものである。
前者だけを取り除く。

---

## 適用したルール

**日本の著作権保護期間は「著作者の死後70年」**(2018年12月30日のTPP整備法により、旧法の死後50年から延長)。
延長時点ですでに保護期間が満了していた著作物は、そのままパブリックドメインに留まる。

本プロジェクトの収録対象は**全員が1948年以前に死去**しており、旧法(死後50年)・新法(死後70年)のいずれの基準でも保護期間は満了している。

翻訳作品については、**原著者と翻訳者の双方**の保護期間満了を確認している(翻訳には翻訳者の著作権が別途発生するため)。

### 原典から訳出したもの

日本語のパブリックドメイン訳が存在しない、または公開されていないため、**保護期間が満了した原典から本プロジェクトで訳出**した。
原文は `original` フィールドに保持しており、訳の妥当性を検証できる。

| 思想家 | 底本 | 底本の権利状況 |
|---|---|---|
| 孔子(前551–前479) | 『論語』原文(漢文) | 古典。[中文Wikisource](https://zh.wikisource.org/wiki/論語) |
| ニーチェ(1844–1900) | Helen Zimmern 英訳『Beyond Good and Evil』(1907) | 訳者 Helen Zimmern は1846–1934年。保護期間満了。[Project Gutenberg #4363](https://www.gutenberg.org/ebooks/4363) |

**訳文の権利**:これらの日本語訳は本プロジェクトで作成したものであり、第三者の翻訳著作権は関与しない。

### 訳出の方法について(明記しておく)

**訳出と現代語化は、AI(Claude)の支援を受けて行っている。** 曖昧にしておくべきことではないので書いておく。

そのうえで、これは「AIに名言を作らせない」という方針と矛盾しない。区別しているのは次の2つである。

| | 内容 | 本プロジェクトでの扱い |
|---|---|---|
| **捏造** | 存在しない引用を生成させ、実在の人物に帰属させる | **一切しない。**誤帰属の温床であり、信頼性を根こそぎ壊す |
| **翻訳・現代語化** | 実在する原文を、別の言語や時代の言葉に移す | **する。**ただし原文を必ず併記し、検証可能にする |

決定的な違いは**原文が存在するかどうか**である。捏造には照合先がないが、訳には必ず原文があり、
`original` フィールドに保持しているため、訳が妥当かどうかを誰でも確かめられる。

**また、アプリの実行時にAIは一切呼び出していない。** 収録テキストは事前に用意した静的なデータであり、
配信も抽選も来歴の表示も、すべてSQLだけで動いている。

## データ構造上の担保

各エントリは以下を保持し、出典を常に追跡できるようにしている。

```json
{
  "text": "過ちを改めないこと、それを過ちという。",
  "author": "孔子",
  "source": "論語 衞霊公第十五",
  "source_url": "https://zh.wikisource.org/wiki/論語",
  "source_type": "classic",
  "original": "過而不改，是謂過矣。",
  "translation_note": "原文(漢文)より訳出"
}
```

`source_url` は全48件に、`original` は訳出・現代語化した27件に付与している。

## 意図的に除外したもの

| 対象 | 除外理由 |
|---|---|
| 存命の作家・現代の著述家の言葉 | 保護期間内 |
| 現代の翻訳(新訳) | 訳者の著作権が存続 |
| ニーチェ 生田長江訳(青空文庫) | 全作品が「作業中」で本文未公開のため取得不可。原典からの訳出に切り替えた |
| ゲーテ『ファウスト』森鴎外訳 | 権利上は問題ないが、戯曲の台詞は文脈なしでは意味が通らないため不採用 |
| AIに生成させた「名言」 | **誤帰属・捏造のリスクがあるため一切使用しない** |

## 補足:なぜここまで確認したか

「偉人の名言」は、インターネット上で誤帰属・捏造が最も蔓延しているジャンルである。
出典を追えない引用を混ぜた時点で、プロダクト全体の信頼性が損なわれる。

本プロジェクトでは、
1. 原典の本文を実際に取得する
2. 出典URLをデータに保持する
3. 訳出したものは原文を併記する

の3点により、**すべての言葉が検証可能な状態**を維持している。
